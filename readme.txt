== Installation ==

### Automatic Installation

1. Log in to your WordPress admin panel
2. Navigate to Plugins > Add New
3. Search for "Gemini Command Center"
4. Click "Install Now" and then "Activate"

### Manual Installation

1. Download the plugin zip file
2. Upload the zip file through WordPress admin (Plugins > Add New > Upload Plugin)
3. Activate the plugin through the 'Plugins' menu

### Setup

1. Navigate to **Gemini Command Center** in your WordPress admin menu
2. Go to **Settings** and enter your Gemini API key
3. Test the connection to ensure everything is working
4. Follow the guided onboarding tour to explore features

== Frequently Asked Questions ==

= Do I need a Gemini API key? =

Yes, you'll need a Google AI Studio API key to use the AI features. You can get one for free at https://makersuite.google.com/app/apikey

= Is this plugin safe to use? =

Absolutely! The plugin follows WordPress security best practices:
* All actions require proper permissions
* Input sanitization and output escaping
* No direct theme file modifications
* Secure nonce verification

= Will this slow down my site? =

No! The plugin only loads its assets on admin pages and uses efficient caching for API responses.

= Can I use this on client sites? =

Yes! The plugin is designed for agencies and developers managing multiple sites.

= What if I don't want AI features? =

You can disable specific modules and use the plugin for just backup, SEO auditing, or other non-AI features.
