== Description ==

Gemini Command Center is a powerful, AI-driven WordPress plugin that provides comprehensive site management capabilities through an intuitive React-based interface. Built with security-first principles and WordPress best practices.

= Key Features =

**🚀 AI-Powered Management**
* Conversational AI agent for natural language site management
* Intelligent recommendations and automated optimizations
* Context-aware assistance with memory of past interactions

**🔍 SEO Command Center**
* Technical SEO audits and issue detection
* Internal link architecture optimization
* Competitive analysis and topical authority planning
* A/B testing engine for headlines and content

**📝 Content Management**
* AI-powered article generation
* On-page SEO optimization
* Social media amplification tools
* Content performance analytics

**💾 Security & Diagnostics**
* Secure backup management (database and full site)
* System health monitoring and diagnostics
* Comprehensive logging and security scanning
* Real-time performance tracking

**🎨 UI/UX Command Center**
* Safe CSS injection (no theme file editing)
* AI-powered design analysis and suggestions
* Color palette and font pairing recommendations

**📊 Reports & Analytics**
* KPI dashboard with key metrics
* Impact measurement and correlation analysis

**⚙️ Advanced Settings**
* Multi-tabbed configuration interface
* API rate limiting and usage control

* Comprehensive system controls

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/gemini-command-center/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Navigate to 'Gemini Command Center' in your admin menu
4. Enter your Gemini API key in Settings > General & API
5. Test the connection and start managing your site with AI

== Frequently Asked Questions ==

= Do I need a Gemini API key? =

Yes, you need a Google Gemini API key to use the AI features. You can obtain one from the Google AI Developer Console.

= Is my data secure? =

Absolutely. The plugin follows WordPress security best practices with nonce validation, capability checks, and secure API communication. No sensitive data is stored insecurely.

= Can I use this on a multisite network? =

Currently, the plugin is designed for single-site installations. Multisite support may be added in future versions.

= Does this modify my theme files? =

No, the UI/UX module only injects CSS through WordPress hooks. It never modifies theme files directly.

= What happens if I deactivate the plugin? =

All plugin data remains in your database. The plugin can be safely reactivated without data loss.

== Privacy Policy ==

This plugin may send data to external services:

**Google Gemini API**: When using AI features, your content and queries are sent to Google's Gemini API for processing. Please review Google's privacy policy for details on how they handle this data.

**No Other External Services**: The plugin does not send data to any other external services without explicit user consent.

**Local Data Storage**: All plugin settings and logs are stored locally in your WordPress database. No data is transmitted to our servers.
